# SpikeClip downloads

Installers for the SpikeClip desktop app (Windows and macOS).

The app needs a license key to run. Get one at https://spikeclip-app.vercel.app
— after you buy, your key and the download buttons are in your account.

| Platform | File |
|---|---|
| Windows 10/11 (installer) | `SpikeClip-Setup.exe` |
| Windows (portable, no install) | `SpikeClip-Portable.exe` |
| macOS, Apple Silicon (M1–M4) | `SpikeClip-mac-arm64.dmg` |
| macOS, Intel | `SpikeClip-mac-x64.dmg` |

The builds are not code-signed yet:
- Windows SmartScreen: click **More info → Run anyway**.
- macOS: the first time, right-click SpikeClip in Applications → **Open** → **Open**.
